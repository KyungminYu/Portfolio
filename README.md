# Kyungmin Yu — Portfolio

A static, responsive portfolio site designed for GitHub Pages.

## Preview locally

Open `index.html` directly, or serve this directory with any static web server.

## Publish with GitHub Pages

1. Create a public repository named `Portfolio` under the `KyungminYu` account.
2. Add these files to the repository root and push them to the `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, `main`, and `/ (root)`.

The site will be available at `https://kyungminyu.github.io/Portfolio/`.

This is a GitHub Pages project site. The root address, `https://kyungminyu.github.io/`, remains available for a future homepage that can link to this portfolio and other projects.

## Content notes

- The site intentionally omits phone numbers, proprietary source code, client information, and coursework solutions.
- Update project links in `index.html` when additional repositories become public.
